> 状态：研究目录已建立，**尚未启动正式统计图形分析**。创建日期：2026-11-23。

本文件夹用于研究**信息图形案例中的基础数据结构与统计图形之间的关系**，与 [01-信息图形数据逻辑](../01-信息图形数据逻辑/) 和 [02-信息图形类型案例](../02-信息图形类型案例/README.md) 关联使用。

## 研究范围（仅登记，待后续指令开展）

- **数据结构**：观察单位、数据字段、变量类型、表格粒度、数据间关系；坚持一行一个观察记录、一列一个变量、每个单元格一个原子值。
- **统计图形**：从实际案例识别所采用的统计图形类型，分析适用的数据关系、映射条件与计算方式。
- **统计处理**：分组、汇总、频数、比例、标准化、排序、分布、关联及时间和空间处理，均需以图面与数据证据核实。
- **视觉映射**：研究位置、长度、面积、颜色、形状、符号、连接关系等视觉编码如何对应数据。
- **案例关联**：将本目录后续建立的统计图形知识与02中的案例分析报告建立Markdown相对链接；01继续只存数据逻辑概念定义，不存案例图片。
