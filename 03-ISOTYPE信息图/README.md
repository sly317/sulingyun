# 03-ISOTYPE信息图｜专项研究项目

本项目独立研究ISOTYPE（International System of Typographic Picture Education，国际图画教育系统），将其视为一种基础的视觉设计与信息表达方法，而不是02目录中的某一种信息图形类型。

## 项目定位

ISOTYPE通过标准化、语义稳定、可重复使用的图形符号，将社会事实、数量和类别转化为可阅读、可比较的视觉表达。它可以与01中的不同数据逻辑、02中的不同视觉类型结合。

## 研究内容

- [专项项目说明与研究框架](./专项项目说明与研究框架.md)：概念定义、方法原则、边界判定、案例分析维度与维护规则。
- 理论与历史：ISOTYPE的历史脉络、理论来源、代表人物与机构、原始文献。
- 符号系统：图形符号的设计语法、标准化、语义映射、单位与重复规则。
- 设计方法：数量表达、图例系统、排列组织、视觉叙事与可读性。
- 案例研究：原始作品、逐例分析报告、可核验的数据与来源。
- 参考文献：书目、论文、档案与在线资料。

## 案例分析原则

每个案例需区分可直接观察的图面事实、可靠来源提供的信息和研究者推断；明确符号含义、统计单位、重复比例、图例、数据来源、01主数据逻辑及02视觉类型。不得将一般图标装饰或仅使用人物图形的作品自动归为ISOTYPE。

## 与仓库其他项目的关系

- 01：回答数据如何组织。
- 02：回答信息图形以何种视觉类型呈现。
- 03：研究ISOTYPE作为基础设计方法如何组织视觉符号。
- 统计图形分析：研究统计图形的结构、计算与视觉映射。

本项目案例可与01、02建立交叉链接，但不改变其各自分类标准。
