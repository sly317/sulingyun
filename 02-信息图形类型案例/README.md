本目录按**信息图形视觉表达类型**存储案例，与[01-信息图形数据逻辑](../01-信息图形数据逻辑/)构成相互独立的双轴分类体系。

## 初始视觉标签

- [01 混合型信息图形（Mixed Charts）](./01-混合型信息图形/说明文档.md)：参考课件第22页，现有1份初步案例报告。
- [02 文字型／列表型信息图形（Informational / List Infographics）](./02-文字型-列表型信息图形/说明文档.md)：参考课件第23页，现有2份初步案例报告。

## 文件夹内部规则

每个标签目录统一管理**一个持续迭代的说明文档、多个案例图片及对应的独立分析报告与基础数据**。案例编号用于关联三者，三件套直接放在标签子文件夹内，无需再建“案例”子目录。

```text
01-混合型信息图形/
  说明文档.md
  CASE-001-原图.png
  CASE-001-分析报告.md
  CASE-001-基础数据.csv
  CASE-002-原图.png
  CASE-002-分析报告.md
  CASE-002-基础数据.csv
```
