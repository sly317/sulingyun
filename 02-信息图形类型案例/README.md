# 02-信息图形类型案例

本目录包含16个视觉表现类型标签，以及1个独立的基础设计方式标签。16种视觉类型各自分文件夹，现有31份图片+案例分析报告+基础数据CSV；ISOTYPE单独归档，**不计入16种信息图形类型**。01主数据逻辑、02视觉类型与ISOTYPE方法标签属于不同维度，可交叉标注。各CSV仅包含从课件可辨认的初始标签/年份，不冒充作者完整原始统计数据。
