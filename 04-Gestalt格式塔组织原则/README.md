# 04-Gestalt格式塔组织原则

本目录记录格式塔知觉组织理论及其在视觉传达、信息图形和数据可视化中的应用，包括定义、概念、案例、设计分析与实践经验。

## 研究范围与数量口径
格式塔原则没有学界统一认可的固定总数。本库以 Wagemans 等（2012）综述为基础，整理为 **7项经典群组原则 + 4项较新的群组原则 = 11项群组原则**，另设 **Figure–Ground 图形与背景组织专题**及 **Prägnanz 简洁律专题**，共13个研究条目。13是本知识库的工作性目录数量，不是学界公认的“13条定律”。

## 每项原则的记录结构
- 01-定义与概念.md：定义、术语、理论来源、机制、边界与争议。
- 02-典型案例/README.md：案例索引、出处、图片来源与版权记录。
- 03-案例分析报告.md：视觉证据、组织方式、知觉结果、设计价值与局限。
- 04-信息图形设计应用.md：信息结构、视觉编码、版式策略、适用场景与反例。
- 05-设计实践经验.md：检查清单、组合应用、常见误用、测试与迭代记录。

## 研究规范
1. 区分格式塔心理学研究结论与设计经验性转译。
2. 每个案例记录可追溯来源；自制示意图明确标注。
3. 分析指出可观察的视觉证据，不只贴原则标签。
4. 多项原则常共同作用，需说明主导线索和辅助线索。
5. 不将所有视觉设计技巧泛化为格式塔定律。
6. 总论文档随文献与案例积累持续更新。
