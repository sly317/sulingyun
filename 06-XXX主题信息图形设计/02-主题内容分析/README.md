# 02｜主题内容分析

## 目标
把宽泛主题转化为清晰的信息问题，并通过与大模型多轮讨论，提出、比较和验证信息组织逻辑与视觉表达方向。大模型提供分析建议，最终判断须由设计者结合资料和数据确认。

## 分析步骤
1. **主题拆解**：核心概念、子主题、关键对象、时间范围、空间范围、利益相关者。
2. **信息关系识别**：时间先后、层级隶属、类别归纳、空间分布、流程因果、比较关系、关联网络等。
3. **数据结构判断**：判断是否适合编年型、层级型、编目型、字母表型、地理型，或多种逻辑组合。不要仅凭主题名称决定类型。
4. **视觉表达判断**：评估文字型/列表型、时间轴、地图、示意图、流程图、比较图、统计图形、词云、照片型、插画型、符号型、混合型等表达手段。
5. **风格方向判断**：讨论平面图形、照片主导、插画、信息符号、ISOTYPE等视觉语言。风格与信息组织逻辑分开记录。
6. **标签筛选**：给出主标签、辅助标签和不适用标签，并说明依据。
7. **形成设计命题**：用一句话说明“为谁、围绕什么问题、通过什么信息关系、帮助读者理解什么”。

## 标签判断框架

| 维度 | 可选标签示例 | 判断依据 |
|---|---|---|
| 数据/信息组织逻辑 | 编年型、层级型、编目型、字母表型、地理型、比较型、流程型、关系型 | 主题内部信息如何组织 |
| 信息图形表现类型 | 文字型/列表型、时间轴型、地图型、示意图型、流程图型、比较型、统计图表型、混合型等 | 信息主要通过何种图形结构呈现 |
| 图像媒介 | 纯文字、图标/符号、插画、照片、地图底图、数据图形 | 主要视觉材料是什么 |
| 视觉风格 | 平面、照片纪实、编辑设计、极简、复古、手绘、ISOTYPE方法等 | 视觉语言与表达气质 |
| 具体手法 | 词云、标注、图例、比例符号、分面、网格、路径、图像拼贴 | 局部表达技术是什么 |

注意：词云是具体表现手法，不等于完整的信息组织逻辑；照片型描述图像媒介，不必然代表信息图形结构；ISOTYPE是基础设计方法，不是02目录中的一种普通视觉类型。

## 与大模型协作的建议提问
请围绕“XXX主题”开展信息设计前期分析：
- 拆解主题的核心对象、子议题与信息关系；
- 分别判断适合的01数据逻辑、02视觉表现类型、图像媒介、视觉风格和具体手法；
- 每个建议给出理由、所需数据、优点、风险及替代方案；
- 区分主标签与辅助标签，不要把词云、照片风格、编年逻辑等不同维度混为一谈；
- 最后提出2—3个可执行的设计方向，并说明需要补充哪些证据。
