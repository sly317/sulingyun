# 06｜视觉编码

## 定位
本阶段偏重设计表达：研究如何把数据和叙事转化为可感知、可阅读、可比较的视觉语言。视觉选择必须回应内容，不以形式堆叠替代信息表达。

## 编码维度
### 1. 基本视觉元素
- 点：位置、数量、对象、节点。
- 线：路径、时间、联系、流向、边界。
- 面：区域、分类、范围、分组。
- 体：体量、层次、空间结构、三维对象。

### 2. 视觉变量与版式
- 色彩：色相、明度、饱和度；建立类别色、顺序色与强调色规则。
- 文字：字体、字号、字重、行距、字距、层级、可读性。
- 构图：网格、对齐、留白、比例、节奏、视觉重心。
- 图像图形：照片、插画、图标、符号、纹理、图例、标注。
- 统计图形：柱形、折线、散点、面积、矩阵、分布与组合图等，依据变量类型选择。
- ISOTYPE：研究符号标准化、重复符号计量、图形语法与图文关系；不能把随意添加图标等同于ISOTYPE。

### 3. 编码决策
每项编码记录：表达对象、数据字段、视觉通道、编码规则、图例/标注、可读性风险、替代方案。
