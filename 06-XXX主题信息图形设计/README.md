# 04｜XXX主题信息图形设计

本项目是一个**具体选题的信息图形设计工作区**。将一个尚待明确的主题（XXX）从问题发现、内容研究、数据搜集与原子化整理，推进到叙事、视觉编码、测试和设计实施。

> XXX 是占位符。确定选题后，将文件夹名称替换为具体主题名称，并同步修改本文件标题及相关索引。

## 项目流程

1. [01 前期调研](./01-前期调研/README.md)：明确主题背景、受众、传播场景、设计目标与核心问题。
2. [02 主题内容分析](./02-主题内容分析/README.md)：与大模型协作分析主题，判断信息组织逻辑、视觉表达类型和适用标签，形成设计方向。
3. [03 数据搜集](./03-数据搜集/README.md)：整理公共数据集、文本文献和自建数据集，记录来源与授权。
4. [04 基础数据集构建](./04-基础数据集构建/README.md)：建立原子化数据表，确保每列一个变量、每个单元格一个值。
5. [05 叙事框架搭建](./05-叙事框架搭建/README.md)：组合基础数据列，形成可验证、可阅读的叙事主题与信息层次。
6. [06 视觉编码](./06-视觉编码/README.md)：重点研究设计表达，包括点线面体、色彩、文字、图像、图形、统计图形及ISOTYPE。
7. [07 信息轮盘测试](./07-信息轮盘测试/README.md)：预留测试方法、记录表与迭代结论，后续补充。
8. [08 设计实施](./08-设计实施/README.md)：完成版式、制作、校对、输出与归档。

## 项目核心原则

- **先研究内容，再确定形式。** 不预先假定主题一定适合编年型、编目型或某种视觉风格。
- **区分不同分类维度。** 编年型、编目型等属于信息组织逻辑；平面风格、照片风格、文字型、词云图等属于不同层级的视觉表达或具体表现手法，不应混为一个标签体系。
- **基础数据原子化。** 一列只表示一个变量；一个单元格只存一个值。名义数据、量化数据、图像文件引用、文本字段均可作为独立变量。
- **叙事由数据关系产生。** 例如“地点名称+GPS坐标”可以支持地图叙事；“地区名称+GDP数值+年份”可以支持地区经济比较或时间变化叙事。
- **视觉编码服务于表达。** 选择视觉语言时，优先考虑信息含义、可读性、准确性与主题气质，而非装饰效果。
- **来源可追溯、结论可复核。** 数据、文献、图像素材和AI辅助判断均应记录来源或生成过程。

- 信息轮盘测试记录（待完善）
- 最终设计文件、输出文件及复盘报告
