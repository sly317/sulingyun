# 苏灵云｜信息图形数据逻辑与类型案例研究库

本仓库用于持续研究信息图形（Information Graphics）的**数据结构、统计图形、视觉编码、信息架构与视觉叙事**。

- [01-信息图形数据逻辑](./01-信息图形数据逻辑/)：五种基础数据组织逻辑的概念定义（只保存Markdown理论文档，不保存图片）。
- [02-信息图形类型案例](./02-信息图形类型案例/README.md)：按视觉表现标签分目录，初始包含混合型、文字／列表型和时间轴型。
- [仓库研究规则](./仓库规则.md)：案例入库、双轴归类、单值数据集、报告与理论动态修订的方法。

## 分类与分析顺序
先依据数据本质确定01五类主逻辑，再选择02视觉类型标签；每个案例按A 数据逻辑、B 统计图形及计算、C 视觉编码、D 数据／信息架构、E 视觉叙事架构分析，并记录设计制作流程与证据边界。

当前初版的案例观察参考用户提供的《第三讲—信息图形类型学》PDF第22—24页；它们仅作为首轮观察依据，统计数值及作者制作过程不得擅自臆测。

建立日期：2026-11-23。首次入库后可通过新案例及GitHub提交历史追踪修订。
