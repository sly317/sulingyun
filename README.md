# 苏灵云｜信息图形数据与视觉类型案例研究库

本仓库研究信息图形的**数据结构→统计图形→视觉编码→信息架构→视觉叙事→制作流程**。

## 三个研究目录

- [01 信息图形数据逻辑](./01-信息图形数据逻辑/)：五种基础组织逻辑及A-E理论定义，仅存Markdown，不存图片。
- [02 信息图形类型案例](./02-信息图形类型案例/README.md)：按16种视觉类型标签归档案例，现有31张PDF原图、31份逐图报告和31份原子化CSV数据。
- [03 统计图形分析](./03-统计图形分析/README.md)：统计图形方法学、RAWGraphs参考与[案例统计图形索引](./03-统计图形分析/案例统计图形索引.md)。

[仓库规则](./仓库规则.md) · [案例清单CSV](./案例清单.csv)

## 分类核心原则

**先判01五大数据逻辑，再归入02的视觉标签。** 二者不是同一分类轴，案例的视觉标题不自动代表底层数据结构。

每份案例按A数据逻辑、B统计图形与计算、C视觉编码、D信息架构、E视觉叙事进行解剖，再从数据清洗、设计选择、版式与校核推定可复现流程。

## 当前图片与数据状态

图片取自用户上传的73页《第三讲—信息图形类型学》PDF第22—38页，直接提取PDF内嵌JPEG，**不是AI重绘**。每组文件以案例ID配对，图片与报告、CSV均已写入GitHub。

CSV已按照“一行一条观察、一列一个变量、一个格只有一个值”整理，现有205条记录，包括65条能够从图面辨认的定量指标；其余主题/部件数据属于结构化视觉观察，不等同于原设计师的全部底层统计数据。读不清的数值不造假，制作步骤标识为研究者可复现推断。
