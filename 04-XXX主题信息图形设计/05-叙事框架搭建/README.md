# 05｜叙事框架搭建

## 目标
从基础数据集中选择若干字段，建立明确的叙事主题、信息关系和阅读顺序。基础数据表保持原子化，叙事框架通过字段组合和分析形成，不回写成混合字段。

## 字段组合示例
- 地点名称 + 纬度 + 经度：地图上的地点分布。
- 地区名称 + GDP数值：地区经济规模比较。
- 地区名称 + 年份 + GDP数值：地区经济变化趋势。
- 人物名称 + 出生年份 + 事件：人物与历史事件的时间叙事。
- 物品名称 + 类别 + 特征：对象编目与分类展示。

## 搭建步骤
1. 明确核心叙事问题：读者最终应理解什么？
2. 选择叙事主体：人物、地点、事件、物品、组织或指标。
3. 选择关键字段：主字段、解释字段、比较字段、定位字段、时间字段。
4. 明确字段之间的关系：对应、排序、聚合、比较、空间定位、因果或关联。
5. 设计信息层次：主叙事、分支主题、细节证据、注释来源。
6. 规划阅读路径：从整体到局部、从时间到事件、从地图到地点、从比较到解释等。
7. 检查叙事是否被数据支持，避免无证据的因果结论。
