# 08｜设计实施

## 目标
将通过前序研究与测试的叙事和视觉方案转化为完整设计成果，并完成事实、数据、视觉和输出质量检查。

## 实施流程
1. 确定最终画幅、媒介、分辨率、色彩模式与输出规格。
2. 建立版式网格、信息层级、阅读路径和模块结构。
3. 导入经过校验的基础数据，保留数据到图形的映射关系。
4. 按视觉编码规范制作图形、图表、地图、照片和符号。
5. 添加标题、导语、注释、图例、来源、单位和必要的方法说明。
6. 检查数据准确性、标签一致性、文字可读性、色彩区分度和版权。
7. 输出展示版、印刷版或屏幕版，并归档源文件与最终文件。
8. 记录设计复盘：有效决策、问题、修改历史和可复用规范。
