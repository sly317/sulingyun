# 信息图形类型与标签

将标签拆成独立维度，避免混淆“组织逻辑、图形类型、图像媒介、风格、局部手法”。

| 维度 | 候选标签 | 主/辅标签 | 选择理由 | 排除项及理由 |
|---|---|---|---|---|
| 信息组织逻辑 | 编年/层级/编目/字母表/地理/比较/流程/关系 | | | |
| 图形结构 | 时间轴/地图/列表/流程图/统计图/示意图/混合 | | | |
| 图像媒介 | 文字/图标/插画/照片/地图底图/数据图形 | | | |
| 视觉风格 | 平面/照片纪实/编辑设计/极简/复古/手绘等 | | | |
| 具体手法 | 词云/标注/拼贴/网格/图例/比例符号等 | | | |

提示：词云是局部表现手法；照片型描述媒介；平面风格描述视觉语言，均不能替代信息组织逻辑。
