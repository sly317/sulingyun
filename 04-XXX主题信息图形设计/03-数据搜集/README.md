# 03｜数据搜集

## 目标
为主题分析和叙事设计建立可信、可追溯、可使用的数据与资料来源。

## 三类来源
### A. 公共数据集
政府开放数据、国际组织数据库、科研数据平台、开放地图数据、公共档案等。记录数据集名称、发布机构、下载地址、更新时间、字段说明、许可协议和使用限制。

### B. 文本文献
学术论文、专著、报告、新闻报道、政策文件、历史档案、网页资料等。记录作者/机构、标题、发布日期、页码或段落、链接、引用内容及可信度。

### C. 自建数据集
实地观察、访谈、问卷、人工标注、图像采集、测量与编码等。记录采集方法、样本范围、时间地点、字段定义、采集者、偏差和伦理事项。

## 质量检查
- 来源是否权威、可访问、可追溯？
- 数据定义、统计口径、时间范围和空间范围是否一致？
- 是否存在缺失值、重复值、抽样偏差或口径变化？
- 图像、文本和数据是否允许使用、改编与公开发布？
- 原始资料与清洗后的数据是否分别保存？

## 阶段产出
建议建立 source-register.csv、原始数据/、文献资料/、自建采集记录/ 等文件；原始文件只读保存，清洗过程另行记录。
