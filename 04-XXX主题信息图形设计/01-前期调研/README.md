# 01｜前期调研

## 目标
判断选题是否值得做、为谁而做、要解决什么信息问题，以及最终信息图的使用场景。

## 调研内容
- 主题背景：主题的定义、边界、历史背景与现实语境。
- 受众分析：目标读者、已有认知、阅读动机与信息需求。
- 使用场景：展览、出版、社交媒体、网页、课堂、公共传播等。
- 传播目标：希望读者看懂什么、比较什么、记住什么或采取什么行动。
- 竞品与案例：搜集相近主题的信息图、数据可视化和视觉传播案例。
- 可行性：数据是否可获得、信息是否可信、制作周期与媒介限制。

## 阶段产出
建议形成《前期调研报告.md》，至少包含：选题缘起、核心问题、受众、场景、调研发现、参考案例、风险与待验证问题。
